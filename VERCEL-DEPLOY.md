# «Живая летопись» на Vercel — пошаговый деплой

## Что куда едет (понимание за 30 секунд)

| Файл | Куда | Зачем |
|---|---|---|
| `index.html` | **Vercel** (твой репозиторий) | Вся игра целиком: HTML + CSS + JS в одном файле, внешних зависимостей нет |
| `src/cf-worker/worker.js` | уже на **Cloudflare** | Бэкенд генерации (текст + картинки), игра зовёт его по URL |
| `main.pjs` | **никуда** (остаётся на Perchance) | Нужен только движку Perchance, на Vercel бесполезен |

Игра на Vercel работает через `AI_BACKEND = "cloudflare"` (уже включен в файле)
и зовёт воркер `https://lia-backend.karimdurik1.workers.dev`. Плагины Perchance
вне Perchance недоступны — в коде стоят проверки, игра не упадёт, а покажет
понятную ошибку, если бэкенд не задан.

## Шаг 0. Что нужно

- Git на компьютере, доступ к твоему репозиторию на GitHub/GitLab.
- Репозиторий уже соединён с Vercel (Deploy on push включён — это default).

## Шаг 1. Склонируй репозиторий (если его нет на компьютере)

```bash
git clone https://github.com/ТВОЙ-НИК/ТВОЙ-РЕПО.git
cd ТВОЙ-РЕПО
git pull
```

Пояснение: `clone` — один раз, дальше только `pull` перед изменениями.

## Шаг 2. Положи файл игры

- Если репозиторий **специально под игру**: скопируй `index.html` из архива
  в **корень** репозитория (рядом с `package.json`/README, если есть).
  Игра откроется по главному адресу проекта: `https://твой-проект.vercel.app`.
- Если в репозитории **уже что-то лежит**: создай подпапку, например
  `living-chronicle/`, и положи `index.html` туда. Игра откроется по адресу
  `https://твой-проект.vercel.app/living-chronicle`.

Пояснение: Vercel для статики ничего настраивать не просит — файл
`index.html` раздаётся автоматически, `vercel.json` не нужен.

## Шаг 3. Закоммить и запушить

```bash
git add index.html
git commit -m "Живая летопись: первая версия игры"
git push
```

Пояснение: Vercel следит за веткой (обычно `main`) и на каждый push сам
собирает деплой. Смотреть прогресс: dashboard Vercel → твой проект →
вкладка Deployments → верхняя запись станет Ready (обычно 30–60 секунд).

## Шаг 4. Проверь игру

1. Открой адрес проекта.
2. Нажми «Начать путешествие» → должен сгенерироваться пролог (идёт через
   Cloudflare-воркер, 5–15 секунд).
3. Шагни в историю → сцена с картинкой.
4. Если вместо текста ошибка — открой консоль браузера (F12 → Console)
   и пришли мне скриншот: по тексту ошибки сразу видно, сеть это или воркер.
   Частые причины: AdBlock режет запросы (проверь без него), кончились
   нейроны Cloudflare (смотри Metrics воркера).

## Шаг 5. Обновление игры (все следующие разы)

Я присылаю новый `index.html` → ты заменяешь им старый → повторяешь шаг 3
(`add/commit/push`) → Vercel сам обновит сайт за минуту. Воркер при этом
трогать не надо, он живёт отдельно.

## Про Telegram (следующий этап, не сейчас)

## Если в превью работает, а на Vercel — нет

Код одинаковый, поэтому причина почти всегда в публикации, а не в игре.
Проверяй по порядку:

1. **Жёсткая перезагрузка.** Открой адрес Vercel → Ctrl+Shift+R
   (на телефоне: закрыть вкладку и открыть заново). Браузер любит отдавать
   старый закэшированный `index.html`.
2. **Что реально лежит на Vercel.** Открой исходник страницы
   (Ctrl+U) и поиском найди `karimdurik2`. Нет — на проде старый файл:
   Vercel → Deployments → верхний деплой должен быть Ready и свежее твоего
   push. Не Ready/ошибка сборки — читай лог деплоя.
3. **Консоль.** F12 → Console → красный текст после нажатия кнопки:
   `worker 502` = упали оба воркера (квоты, смотри Metrics обоих аккаунтов);
   `Failed to fetch` = сеть/блокировщик (п.4); `нет URL воркера` = файл
   совсем старый. Пришли мне этот текст — скажу точно.
4. **Блокировщики.** AdBlock/uBlock и «частный DNS» на телефоне режут
   запросы к `*.workers.dev`. Проверь с выключенным блокировщиком.
5. **Здоровье воркеров.** Открой в браузере оба
   `<URL>/health` → везде `{"ok":true,...}`. Не открывается — проблема
   в самом воркере/аккаунте, а не в игре.

## Откат

- Сайт сломался после обновления: Vercel → Deployments → предыдущий
  деплой → троеточие → Promote to Production. Сайт вернётся за секунды.
- Cloudflare не отвечает: игра сама откатится на Perchance? Нет — вне
  Perchance запасного пути нет, покажет экран ошибки с кнопкой повтора.
  Лечится проверкой воркера (`/health` в браузере).
